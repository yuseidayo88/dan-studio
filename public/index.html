書き出し設定 +

WAV / 24bit推奨 / 44.1kHz または 48kHz（録音時と同じ設定）。ボーカルはモノラル推奨です。

EQ・コンプ・リバーブなどはOFFにし、音割れのない状態で書き出してください。MP3をWAVに変換する必要はありません。元のWAVをお送りください。

頭出しについて +

すべてのボーカルトラックを、曲の同じ開始位置（0:00）から書き出してください。途中から歌が始まるトラックも、無音部分を含めて同じ長さで書き出すと位置がずれません。

難しい場合は、提出前にご相談ください。

送り方 +

すべてのデータを1つのZIPにまとめ、ギガファイル便（保存期間30日以上を推奨）またはGoogle Driveで共有してください。

ダウンロードできる共有URLをXのDMにお送りください。音源の使用許可も事前にご確認ください。

05 / QUESTIONS

FAQ.

よくあるご質問

ピッチ補正は料金に含まれますか？ +

軽度なピッチ・タイミング補正は基本料金に含まれます。大幅な補正は音源確認後にお見積もりします。

録音データが1つしかなくても大丈夫ですか？ +

メインボーカル1本と伴奏音源があればご相談可能です。ハモリ・ダブルは必須ではありません。

修正はどこまでお願いできますか？ +

音量・EQ・リバーブ・ディレイ・軽度な補正など、当初のご依頼範囲内の調整が対象です。複数箇所の希望を1回にまとめてお伝えいただけます。

支払い・キャンセルのルールは？ +

お見積もりに同意後、原則先払いとなります。制作開始前のキャンセルは全額返金。着手後は制作の進捗に応じて精算します。詳しくは利用規約をご覧ください。

MIX実績として公開されますか？ +

ご本人の許可がない音源を、実績・サンプルとして公開することはありません。
